# Лабораторна робота №1 — Варіант 11: Мобільний тариф

**Дисципліна:** Функційне програмування.

Програма розраховує `monthly_cost` для кожного мобільного абонента за витратами `minutes`, `sms`, `traffic` (у ГБ), правилами `tariff` і `bonus`. Чисте ядро `core.py` не виконує I/O і не змінює вхідні записи. У `app.py` містяться виведення та конфігурація політик. `tests/test_core.py` перевіряє формули, референтну прозорість, відсутність мутацій і `Callable`.

## Структура

- `core.py` — чисті функції та фабрика `make_processor`;
- `app.py` — демонстрація й `render_report`;
- `tests/test_core.py` — тести pytest;
- `requirements.txt` — інструменти розробки.

## Запуск

Відкрийте термінал у папці `lab01`:

```bash
python -m pip install -r requirements.txt
python app.py
python -m pytest -q
python -m mypy core.py app.py
python -m black --check .
python -m ruff check .
```

## Демонстраційний розрахунок

Тариф Standard: 150 грн/місяць, 100 хв, 50 SMS, 10 ГБ; понад ліміти: 1.5 грн/хв, 1 грн/SMS, 20 грн/ГБ. Бонус — знижка 10%. Для 120 хв, 40 SMS, 12 ГБ: `(150 + 20*1.5 + 0 + 2*20)*0.9 = 198.00 грн`.

Усі значення демонстраційні. Політики тарифікації, бонусу та фільтрації можна змінювати незалежно.
